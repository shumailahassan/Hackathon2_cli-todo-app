# Quickstart: Phase I Basic Todo Console App

## Getting Started

1. **Install Dependencies**:
   ```bash
   uv sync
   ```

2. **Run the Application**:
   ```bash
   uv run src/todo_app/main.py
   ```

## Usage

Once in the REPL loop, you can use the following commands:
- `add`: Add a new task.
- `list`: Show all tasks.
- `update`: Edit a task's title or description.
- `delete`: Remove a task.
- `toggle`: Mark a task as complete or incomplete.
- `exit`: Quit the app.
